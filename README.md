# Owen Bernstein Portfolio Website

A static, tech-inspired personal portfolio for Owen Bernstein.

## Files

- `index.html` — site structure and content
- `styles.css` — full responsive styling
- `script.js` — navigation, animations, copy email, typing effect
- `July_Resume_2026` — resume linked from the site

## How to preview locally

Open `index.html` in your browser.

## How to deploy with GitHub Pages

1. Create a new GitHub repository, for example `owen-portfolio`.
2. Upload all files in this folder to the repository.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/root` folder.
6. Save. GitHub will give you a live website URL.

## Easy edits

- Change text inside `index.html`.
- Adjust colors in `styles.css` under the `:root` variables.
- Replace the resume PDF by keeping the same filename: `Owen_Bernstein_Resume.pdf`.
